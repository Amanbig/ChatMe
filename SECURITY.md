# Security Policy

ChatMe takes the security of our application and users seriously.

## Supported Versions

Only the latest release receives active security patches.

| Version | Supported          |
| ------- | ------------------ |
| 0.5.x   | :white_check_mark: |
| < 0.5.0 | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability in ChatMe, please **do not** report it using public GitHub issues.

Instead, please responsibly disclose it by either:
1. Opening a **Private Security Advisory** under the repository's "Security" tab on GitHub.
2. Contacting the project maintainer directly via GitHub profile.

Please include:
- A clear description of the vulnerability.
- Steps to reproduce the issue or proof-of-concept.
- Potential impact and affected platforms (macOS, Windows, Linux).

We will investigate and acknowledge your report within 48-72 hours and provide updates on fixes.
