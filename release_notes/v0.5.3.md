# ChatMe v0.5.3

### Highlights
- **⚡ Hybrid Architecture**:
  - Rust backend handles all external HTTP requests, eliminating browser CORS limitations.
- **🌐 13 AI Providers Supported**:
  - Expanded provider ecosystem: OpenAI, Anthropic Claude, Google Gemini, Ollama, LMStudio, Mistral AI, DeepSeek, Groq, Perplexity, OpenRouter, Together AI, Kimi (Moonshot), and custom OpenAI-compatible endpoints.
- **📡 Native Streaming**:
  - Optimized streaming implementations for OpenAI, Anthropic, and Google Gemini with lower latency and smoother response chunks.
- **🔌 Model Context Protocol (MCP)**:
  - First-class support for MCP servers and tools, enabling deep developer ecosystem integrations.
- **🛡️ Enhanced Permission System**:
  - Upgraded permission dialogs and granular access control for tool execution.
- **🎨 UX & UI Improvements**:
  - Improved message deletion flow and confirmation.
  - Welcome screen auto-send and polished starter prompts.
  - Responsive window dimension improvements.
