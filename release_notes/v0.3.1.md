# ChatMe v0.3.1

### Highlights
- **Speech Features**:
  - Integrated Speech-to-Text (STT) for voice message dictation.
  - Added Text-to-Speech (TTS) for natural voice playback of model responses.
  - Real-time transcription feedback and voice customization options.
- **Agentic Mode Foundations**:
  - Initial system interaction capabilities (file opening and manual tool triggers).
- **Message Rendering Improvements**:
  - Polished markdown output, code block formatting, and message flow.
