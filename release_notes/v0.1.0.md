# ChatMe v0.1.0

Initial public release of ChatMe — a modern cross-platform AI chat application built with Tauri, React, and TypeScript.

### Features
- Multi-provider AI chat support (OpenAI, Anthropic Claude, Google Gemini, Ollama, etc.).
- Responsive UI with Light and Dark theme modes.
- Markdown rendering with syntax highlighting.
- Cross-platform desktop builds (macOS, Linux, Windows).
