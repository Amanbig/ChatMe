# ChatMe v0.4.0

### Highlights
- **Enhanced Agent Mode**:
  - Full system interaction: execute terminal commands, launch applications, and manage system processes.
  - Interactive Command Execution Cards with timing details, expandable outputs, and one-click copy buttons.
  - Natural AI flow: AI can explain, execute commands, and summarize results within a single conversation step.
- **Safety & Permissions**:
  - Permission confirmation dialogs for potentially destructive system operations.
- **Keyboard Shortcuts**:
  - Quick focus shortcut (`Ctrl+K`) and repeat command shortcut (`Ctrl+R`).
- **UI & Experience Improvements**:
  - Redesigned settings page.
  - Enhanced dark/light theme polish.
